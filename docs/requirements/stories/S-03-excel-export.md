## Story

As an asset manager, I want to export the asset list to an .xlsx file,
so that I can share the inventory with people who have no access to the
system.

## Acceptance criteria

- [ ] Export button on the device list page
- [ ] Exported rows respect the filters currently applied
- [ ] File opens in Excel and LibreOffice with no repair prompt
- [ ] Header row present; column order matches the screen
- [ ] Dates render as dates, not as serial numbers or text

## Out of scope

CSV and PDF output; scheduled or emailed exports.
