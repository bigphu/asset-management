## Story

As an asset manager, I want to choose what the exported file contains
and how it looks, and save that choice, so that I do not reconfigure the
same monthly report every time.

## Acceptance criteria

- [ ] Pick which columns appear and in what order
- [ ] Rename column headers
- [ ] Choose a date format
- [ ] Name the export profile and save it
- [ ] Pick a saved profile at export time
- [ ] Edit and delete saved profiles

## Out of scope

Sharing profiles between users; uploading an .xlsx template; conditional
formatting rules.

## Notes

Triggers P-CUS-01, P-CUS-02, P-CUS-03. Because profiles are themselves a
managed resource, this story re-instantiates P-ASS-05 as a second
occurrence.
